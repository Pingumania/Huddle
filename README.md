# Huddle

Huddle is a boilerplate that simplifies addon creation.

Yes, you can use this if you want.
No, you should not depend on it being stable.

To use it, embed it in your addon (e.g. under `Libs/Huddle/`) and list `Libs\Huddle\Embed.xml` as a file entry in your addon's own toc file.

> [!WARNING]
> Made for my own addons. No guarantees anything stays or works.
